02e-preflight-zadanie

Operacja wyznacza kształt trasy: skoki = jedno lotnisko, pozostałe = dwa pola start / lądowanie — a przy skokach dochodzi „Domyślny skład skoczków" (wartość startowa każdego załadunku bez własnej deklaracji, 2026-08-17). Wariant z operacją „Przelot", czyli parą pól start / lądowanie pod nakładką. Podpowiedź, nie bramka — kod spoza katalogu (przelot za granicę) wpisuje się normalnie. Bez sieci
